# Random Block Placer

Мод добавляет предмет, позволяющий случайно выбрать блок из набора, который составляет игрок.

Для Minecraft 26.3. Сборка и запуск требуют JDK 25: настройте `JAVA_HOME`,
а в IntelliJ IDEA выберите JDK 25 в Settings → Build Tools → Gradle → Gradle JVM.

Команды из корня проекта (PowerShell):

```powershell
.\gradlew.bat build
.\gradlew.bat detekt
.\gradlew.bat runClient
```
